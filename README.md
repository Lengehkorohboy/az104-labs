# AZ-104: Microsoft Azure Administrator Labs

Personal lab exercises, scripts, and notes while studying for the **AZ-104: Microsoft Azure Administrator** certification.

## Overview

This repository documents my hands-on experience preparing for the Microsoft Azure Administrator Associate (AZ-104) certification through practical, real-world Azure administration projects.

As a Senior IT Enterprise Desktop Administrator with experience supporting enterprise healthcare environments, I created this portfolio to demonstrate my skills in Azure infrastructure, identity management, governance, networking, compute, monitoring, security, and automation.

Each project aligns with key AZ-104 exam objectives and showcases my ability to deploy, manage, secure, and monitor cloud resources using Microsoft Azure.
